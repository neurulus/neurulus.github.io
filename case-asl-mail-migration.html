Advanced Systems Laboratory

Move an essential service and strengthen its foundation.

Mail-server migration and hardening for Advanced Systems Laboratory.

Mail infrastructure
1Service-migration engagement
MailEssential service
The challengeWhy NeurulusHow the platform solved itThe outcome

The challenge.

An essential communication service has to move without losing sight of the environment it will run in next. Migration and security configuration are connected parts of that change.

Why Neurulus fit.

The important change included both the mail service and the environment it would run in next. Neurulus joined migration with target-system hardening and handover. Treating the service and its configuration as one deployment kept the security work connected to the operating change the laboratory needed.

How the platform addressed it.

Neurulus deployed the platform around the mail-server migration for Advanced Systems Laboratory. The engagement combined the service migration with hardening of the target operating environment.

Implementation and handover covered the migrated service and its resulting configuration. Migration and hardening were handled within the same assignment, keeping the new operating environment in view throughout the change.

In the deployment

  • Mail-server migration.
  • Hardening of the target operating environment.
  • Implementation and handover within the recorded project scope.

The outcome.

ASL gained the migrated mail service with its target environment hardened as part of the same engagement. The operating change and the security work were delivered together.
